# MAPS: A Multilingual Benchmark for Agent Performance and Security

ATR source ID: `SRC-MAPS-2026`

## 来源支持的内容

Across 805 tasks translated into 11 languages, agent performance and security degrade outside English; the reported severity varies by task and correlates with the amount of translated input.

## 来源不支持 / 不能推出的内容

The correlation does not identify tokenization, reasoning budget, translation quality, or a causal mechanism; translation-derived instances are not evidence about native user behavior.
