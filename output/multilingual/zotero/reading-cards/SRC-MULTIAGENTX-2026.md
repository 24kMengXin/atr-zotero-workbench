# MultiAgent-X: Multilingual Agentic Function-Calling Benchmark

ATR source ID: `SRC-MULTIAGENTX-2026`

## 来源支持的内容

The released synthetic culturally grounded dataset includes ambiguous and multi-turn-clarification categories, including cases where an agent must request clarification before acting.

## 来源不支持 / 不能推出的内容

Repository documentation alone is not a peer-reviewed novelty verdict or proof of native-language pragmatic validity; its provided labels do not by themselves establish a paired authorization-state causal oracle.
