# MASSIVE-Agents: A Benchmark for Multilingual Function-Calling in 52 Languages

ATR source ID: `SRC-MASSIVE-AGENTS-2025`

## 来源支持的内容

该论文在 52 种语言上以严格 AST 准确率评估多语言 function calling，并报告英语到目标语言的显著分数差异。

## 来源不支持 / 不能推出的内容

它不证明单个分数差异完全来自能力，也不记录每个题目的执行值约定。
