# XQ-MEval: A Dataset with Cross-lingual Parallel Quality for Benchmarking Translation Metrics

ATR source ID: `SRC-XQ-MEVAL-2026`

## 来源支持的内容

Translation metric averages can diverge from human judgment across languages; the study uses native-speaker reliability filtering in a translation-metric setting.

## 来源不支持 / 不能推出的内容

It does not test structured action scoring, function calls, or executable conventions.
