# InjecAgent: Benchmarking Indirect Prompt Injections in Tool-Integrated Large Language Model Agents

ATR source ID: `SRC-INJECAGENT-2024`

## 来源支持的内容

InjecAgent benchmarks indirect prompt injections in tool-integrated agents over 1,054 cases, 17 user tools and 62 attacker tools.

## 来源不支持 / 不能推出的内容

It does not vary language or measure a cross-lingual trust effect.
