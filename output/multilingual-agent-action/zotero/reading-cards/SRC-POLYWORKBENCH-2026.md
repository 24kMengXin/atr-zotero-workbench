# PolyWorkBench: Benchmarking Multilingual Long-Horizon LLM Agents

ATR source ID: `SRC-POLYWORKBENCH-2026`

## 来源支持的内容

PolyWorkBench directly evaluates 67 multilingual long-horizon workplace workflows across ten languages with heterogeneous inputs, tools, structured outputs, executable/structural checks and LLM semantic assessment; it reports degradation relative to monolingual counterparts.

## 来源不支持 / 不能推出的内容

It does not isolate a single language role or establish whether any observed gap is caused by an evaluation judge rather than the agent trajectory.
