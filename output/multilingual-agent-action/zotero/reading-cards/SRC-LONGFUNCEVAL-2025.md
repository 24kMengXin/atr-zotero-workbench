# LongFuncEval: Measuring the effectiveness of long context models for function calling

ATR source ID: `SRC-LONGFUNCEVAL-2025`

## 来源支持的内容

Long tool catalogs, long tool responses, and long multi-turn dialogue contexts substantially degrade function-calling performance as context length and answer position vary.

## 来源不支持 / 不能推出的内容

It does not vary the language of user query, schema, or tool response, nor attribute effects to multilingual tokenization.
