# MultiPragEval: Multilingual Pragmatic Evaluation of Large Language Models

ATR source ID: `SRC-MULTIPRAGEVAL-2024`

## 来源支持的内容

Multilingual pragmatic inference can be evaluated across English, German, Korean and Chinese using Gricean conversational-maxim categories.

## 来源不支持 / 不能推出的内容

It does not measure tool actions, authorization, clarification policies, or real consequences of a pragmatic misinterpretation.
