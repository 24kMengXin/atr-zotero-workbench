# MEMERAG: A Multilingual End-to-End Meta-Evaluation Benchmark for Retrieval Augmented Generation

ATR source ID: `SRC-MEMERAG-2025`

## 来源支持的内容

Native-language expert assessment can reveal language-specific differences in RAG faithfulness and relevance.

## 来源不支持 / 不能推出的内容

It does not isolate language-mismatched evidence, reader verification, or a source-language disclosure intervention.
