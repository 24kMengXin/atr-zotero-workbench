# ClarifyMT-Bench: Benchmarking and Improving Multi-Turn Clarification for Conversational Large Language Models

ATR source ID: `SRC-CLARIFYMT-2025`

## 来源支持的内容

LLMs exhibit under-clarification bias in complex multi-turn ambiguity; the benchmark separates ambiguity types and user behaviors.

## 来源不支持 / 不能推出的内容

It is open-domain rather than multilingual tool authorization, uses partly LLM-authored data and LLM judging, and has no deterministic tool-effect oracle.
