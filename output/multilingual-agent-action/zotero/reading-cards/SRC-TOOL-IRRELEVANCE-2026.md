# Do LLMs Know Tool Irrelevance? Demystifying Structural Alignment Bias in Tool Invocations

ATR source ID: `SRC-TOOL-IRRELEVANCE-2026`

## 来源支持的内容

The paper identifies structural alignment bias: models call a tool when query attributes can fill its parameters even if the tool does not serve the user's goal, and it studies tool refusal mechanistically.

## 来源不支持 / 不能推出的内容

It does not establish all multilingual refusal phenomena or a language-specific cause.
