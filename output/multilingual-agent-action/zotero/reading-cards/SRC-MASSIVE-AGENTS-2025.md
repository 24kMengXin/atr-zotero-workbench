# MASSIVE-Agents: A Benchmark for Multilingual Function-Calling in 52 Languages

ATR source ID: `SRC-MASSIVE-AGENTS-2025`

## 来源支持的内容

The paper evaluates multilingual function calling with strict AST accuracy at 52-language scale and reports substantial English-to-target score gaps.

## 来源不支持 / 不能推出的内容

It does not establish that an individual score gap is wholly a capability difference or document every item-level execution convention.
