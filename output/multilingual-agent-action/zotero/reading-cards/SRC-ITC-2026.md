# Enhancing Tool Calling in LLMs with the International Tool Calling Dataset

ATR source ID: `SRC-ITC-2026`

## 来源支持的内容

ITC reports 3,571 real APIs, 17,540 tasks, and 29 task languages; it separately measures tool selection and invocation and reports omission/parameter errors.

## 来源不支持 / 不能推出的内容

It does not isolate catalog retrieval from generative selection, and its cited release is an anonymous repository rather than a revision-pinnable public artifact.
