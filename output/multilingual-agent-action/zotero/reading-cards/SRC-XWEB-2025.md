# X-WebAgentBench: A Multilingual Interactive Web Benchmark for Evaluating Global Agentic System

ATR source ID: `SRC-XWEB-2025`

## 来源支持的内容

Multilingual planning and interaction can be evaluated in a web environment, and cross-lingual alignment has been tested as an intervention.

## 来源不支持 / 不能推出的内容

It does not isolate representation length from semantic, cultural, interface, or translation differences, nor establish a reasoning-budget mechanism.
