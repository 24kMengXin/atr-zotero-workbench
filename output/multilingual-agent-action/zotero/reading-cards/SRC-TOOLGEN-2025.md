# ToolGen: Unified Tool Retrieval and Calling via Generation

ATR source ID: `SRC-TOOLGEN-2025`

## 来源支持的内容

ToolGen directly addresses large tool vocabularies and context-length pressure by representing tools with unique tokens, evaluated at more than 47,000 tools.

## 来源不支持 / 不能推出的内容

It does not examine multilingual context inflation or language-conditioned tool-call failure.
