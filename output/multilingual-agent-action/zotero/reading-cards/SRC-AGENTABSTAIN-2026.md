# AgentAbstain: Do LLM Agents Know When Not to Act?

ATR source ID: `SRC-AGENTABSTAIN-2026`

## 来源支持的内容

Paired executable tasks can give an independent act-versus-abstain oracle; the release reports 263 paired tasks in 42 environments and a best paired score of 59.5% across 17 frontier models.

## 来源不支持 / 不能推出的内容

It does not test multilingual or pragmatic realization effects, and does not establish that a language-specific wording difference changes authorization behavior.
