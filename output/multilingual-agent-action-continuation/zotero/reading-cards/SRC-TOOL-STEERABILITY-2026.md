# Tool Calling is Linearly Readable and Steerable in Language Models

ATR source ID: `SRC-TOOL-STEERABILITY-2026`

## 来源支持的内容

Tool choice is internally decodable and causally steerable on fixed-menu synthetic and real API benchmarks; arguments adapt when the selected tool changes.

## 来源不支持 / 不能推出的内容

It does not test multilingual localization of API identifiers, identifier-preservation conventions, or a retrieval stage before tool selection.
