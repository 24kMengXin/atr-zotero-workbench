# Multilingual Prompt Localization for Agent-as-a-Judge: Language and Backbone Sensitivity in Requirement-Level Evaluation

ATR source ID: `SRC-MULTILINGUAL-AGENT-JUDGE-2026`

## 来源支持的内容

Across 55 development tasks, localized judge prompt stacks and judge backbones interact; the work reports language-conditioned backbone changes and a large partial-localization ablation effect, showing that judge language is a consequential evaluation variable.

## 来源不支持 / 不能推出的内容

It does not establish human-ground-truth calibration for multilingual long-horizon workplace workflows, nor that every multilingual agent benchmark has the same judge artifact.
