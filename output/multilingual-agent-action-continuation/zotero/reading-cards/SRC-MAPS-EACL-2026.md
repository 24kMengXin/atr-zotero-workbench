# MAPS: A Multilingual Benchmark for Global Agent Performance and Security

ATR source ID: `SRC-MAPS-EACL-2026`

## 来源支持的内容

MAPS translates four agent benchmarks into eleven languages, verifies a translation subset, measures multilingual degradation with exact/reference outcomes where available, and tests deterministic and agent-chosen translation as partial explanations.

## 来源不支持 / 不能推出的内容

It does not factorially vary evaluator-localization treatments against a common independent action oracle; its translation-quality LLM judge evaluates the benchmark adaptation rather than judging the agent action outcome.
