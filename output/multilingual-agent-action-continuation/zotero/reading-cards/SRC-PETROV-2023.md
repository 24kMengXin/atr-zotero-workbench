# Language Model Tokenizers Introduce Unfairness Between Languages

ATR source ID: `SRC-PETROV-2023`

## 来源支持的内容

Semantically translated text can differ sharply in tokenizer length (reported up to 15x), affecting cost, latency and usable context before model inference.

## 来源不支持 / 不能推出的内容

It does not test LLM agents, tool calls, controlled output reasoning budgets, or an intervention that makes agent decisions representation-invariant.
