# Cross Lingual Auto Evaluation: A Comprehensive Framework for Multilingual LLM Evaluation

ATR source ID: `SRC-CIA-ACL-2025`

## 来源支持的内容

CIA/RECON provides manually reviewed multilingual prompts and human scores, and directly studies mixed-language evaluator inputs, rubrics, and English references.

## 来源不支持 / 不能推出的内容

It evaluates open-ended LLM responses rather than tool-mediated agent trajectories with executable same-task outcome truth.
