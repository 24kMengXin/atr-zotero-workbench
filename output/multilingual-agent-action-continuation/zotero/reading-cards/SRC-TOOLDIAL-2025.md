# ToolDial: Multi-turn Dialogue Generation Method for Tool-Augmented Language Models

ATR source ID: `SRC-TOOLDIAL-2025`

## 来源支持的内容

ToolDial provides public multi-turn tool dialogues with API output-to-input dependency graphs and evaluates next actions/parameter extraction.

## 来源不支持 / 不能推出的内容

It does not create multilingual user/observation language conditions or validate translation of tool results.
