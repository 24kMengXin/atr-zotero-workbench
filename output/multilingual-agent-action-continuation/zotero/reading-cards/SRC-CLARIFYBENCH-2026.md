# Structured Uncertainty guided Clarification for LLM Agents

ATR source ID: `SRC-CLARIFYBENCH-2026`

## 来源支持的内容

ClarifyBench operationalizes execute-versus-ask decisions in multi-turn tool use, with a user simulator, ground-truth tool calls, explicit/ambiguous/infeasible requests, and a structured uncertainty method.

## 来源不支持 / 不能推出的内容

The paper contains no multilingual, indirect-request, or authorization treatment; it therefore neither validates nor leaves novel any multilingual pragmatic-authorization composition by itself.
