# AutoGen MCP adapter bug: valid tool schema is converted incorrectly on the client

ATR source ID: `CTX-AUTOGEN-MCP-ADAPTER-2025`

## 来源支持的内容

A reproducible maintainer issue documents an agent client failing to use an otherwise valid MCP echo tool because its adapter converts the received inputSchema into an incompatible Python typing object. The issue locates the immediate failure in client-side interface handling, not in the tool server.
