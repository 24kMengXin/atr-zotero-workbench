# Beyond Function Calling: Benchmarking Tool-Using Agents under Tool-Environment Unreliability

ATR source ID: `SRC-TOOLBENCH-X-2026`

## 来源支持的内容

ToolBench-X frames recoverable tool hazards—specification drift, invocation error, execution failure, output drift and cross-source conflict—as an action-recovery problem, with deterministic tools and canonical answers; it reports a reliability gap not closed by more inference budget.

## 来源不支持 / 不能推出的内容

It does not test multilingual hazard messages, multilingual agent behavior, or a language-specific recovery mechanism.
