# Configure multilingual agents in Dynamics 365 Contact Center

ATR source ID: `SRC-MS-MULTILINGUAL-CONTACT-CENTER-2026`

## 来源支持的内容

An official multilingual contact-center workflow treats language configuration, primary-language fallback, mismatch warnings and language-specific hand-off/escalation as operational configuration concerns.

## 来源不支持 / 不能推出的内容

It does not report that localized diagnostic/error text changes an agent's hazard diagnosis or recovery action.
