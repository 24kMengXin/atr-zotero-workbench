# Making Task-Oriented Dialogue Datasets More Natural by Synthetically Generating Indirect User Requests

ATR source ID: `SRC-INDIRECTREQUESTS-2025`

## 来源支持的内容

Indirect user requests are a concrete pragmatic construct and can be generated with an LLM pipeline under explicit linguistic criteria for task-oriented dialogue evaluation.

## 来源不支持 / 不能推出的内容

It is not an agent tool-execution, authorization, or multilingual evaluation and provides no action-state oracle.
