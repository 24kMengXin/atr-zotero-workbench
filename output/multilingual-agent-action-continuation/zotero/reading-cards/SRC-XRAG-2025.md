# XRAG: Cross-lingual Retrieval-Augmented Generation

ATR source ID: `SRC-XRAG-2025`

## 来源支持的内容

Cross-lingual RAG distinguishes query, retrieved-document, and answer language; it reports response-language and cross-language integration failures in controlled retrieval settings.

## 来源不支持 / 不能推出的内容

It does not establish that source-language disclosure changes a reader verification decision or that a new provenance construct is unoccupied.
