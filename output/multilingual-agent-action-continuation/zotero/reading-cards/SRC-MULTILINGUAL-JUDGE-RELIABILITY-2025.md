# How Reliable is Multilingual LLM-as-a-Judge?

ATR source ID: `SRC-MULTILINGUAL-JUDGE-RELIABILITY-2025`

## 来源支持的内容

Across five tasks and 25 languages, uncalibrated multilingual LLM judges show inconsistent agreement, particularly for lower-resource languages.

## 来源不支持 / 不能推出的内容

It does not rule out a calibrated screening role after a human reference set exists.
