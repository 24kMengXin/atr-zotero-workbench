# Token Cost Inequality: Measuring Tokenization Disparities Across Scripts in Roman Urdu and Urdu

## 来源支持的内容

Aligned Urdu/Roman-Urdu comparisons measure token cost, fragmentation, and fixed-budget input retention across cl100k, mT5, and ByT5; tokenization disparity is tokenizer-dependent and token cost alone does not explain retention.
