# Model Context Protocol schema-convergence record

ATR source ID: `SRC-MCP-SCHEMA-CONVERGENCE-2026`

## 来源支持的内容

The official MCP record documents that clients and servers had diverged over JSON Schema dialect and validation behavior for tool input/output schemas; the later specification changelog records JSON Schema 2020-12 as the default dialect and tool execution errors as a self-correction path.

## 来源不支持 / 不能推出的内容

It provides no multilingual evaluation, no evidence about natural-language parameter values, and no estimate of user harm. It only establishes that executable interface interpretation is a live interoperability concern.
