# The Token Tax: Systematic Bias in Multilingual Tokenization

ATR source ID: `SRC-TOKEN-TAX-2026`

## 来源支持的内容

Across 10 LLMs and 16 African languages on AfriMMLU, token fertility is reported to predict accuracy; it establishes that a generic fertility-to-downstream-performance association is not a new claim.

## 来源不支持 / 不能推出的内容

It does not study function calling, argument-value language mismatch, held-out-language prediction, or a tokenization effect separated from resource tier in a multilingual agent setting.
